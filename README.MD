# **Ascension Masque**

***

**Ascension Masque** is an add-on for World of Warcraft that adds custom skins for the [Masque](https://www.curseforge.com/wow/addons/masque) add-on.

## Key Features

* **Ascension** — A zoomed square (1:1) skin with clean, abbreviated keybind labels.
* **Ascension Wide** — A 16:9 widescreen skin (38x25) for a different aspect ratio.
* **Hotkey Abbreviations** — Automatically shortens keybind text on your action bars (e.g. `Shift-1` → `S1`, `Mouse Wheel Up` → `WU`, `Command` → `⌘`).
* **Personalization Panel** — Clean settings UI to customize the look via `/am` or ESC > Options > Ascension Masque:
  * Toggle hotkey abbreviations on/off
  * Adjust hotkey and count text size and position dynamically
  * Adjust icon zoom level (square skin only)

## Requirements

* [Masque](https://www.curseforge.com/wow/addons/masque)
* AscensionSuit

**Ascension Masque** es un add-on para World of Warcraft que añade skins personalizados para el add-on [Masque](https://www.curseforge.com/wow/addons/masque).

## Características Principales

* **Ascension** — Un skin cuadrado (1:1) ampliado con texto de teclas abreviado y limpio.
* **Ascension Wide** — Un skin panorámico 16:9 (38x25) para una relación de aspecto diferente.
* **Abreviación de Teclas** — Acorta automáticamente el texto de las asignaciones en tus barras de acción (ej. `Shift-1` → `S1`, `Mouse Wheel Up` → `WU`, `Command` → `⌘`).
* **Panel de Personalización** — Interfaz limpia para ajustar el aspecto visual vía `/am` o desde ESC > Opciones > Ascension Masque:
  * Activar/desactivar la abreviación de teclas
  * Ajustar el tamaño y posición del texto de teclas y cantidad de forma dinámica
  * Ajustar el nivel de zoom de los iconos (solo skin cuadrado)

## Requisitos

* [Masque](https://www.curseforge.com/wow/addons/masque)
* AscensionSuit
